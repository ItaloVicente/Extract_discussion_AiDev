## 📝 Pull Request Body (Autor: Copilot)

> This PR implements a new DNS provider for Alibaba Cloud Edge Security Acceleration (ESA) service, enabling DDNS updates for ESA-managed domains.
> 
> ## Features
> 
> ### Core Functionality
> - **Full ESA API integration** using ACS3-HMAC-SHA256 signature authentication
> - **Automatic domain parsing** with support for subdomains and root domains
> - **Complete DNS record lifecycle** (Create, Read, Update) via ESA APIs:
>   - `ListSites` - Query site IDs
>   - `ListRecords` - Query existing DNS records  
>   - `CreateRecord` - Create new DNS records
>   - `UpdateRecord` - Update existing DNS records
> 
> ### Advanced Configuration Options
> - **TTL and comment/remark support** for record metadata
> 
> ## Usage Examples
> 
> ### Basic Configuration
> ```json
> {
>     "id": "LTAI4xxx",
>     "token": "your_secret_key", 
>     "dns": "aliesa",
>     "ipv4": ["www.example.com", "api.example.com"]
> }
> ```
> 
> ## Use Case
> Perfect for dynamic IP scenarios where NAS or other services act as ESA CDN origin hosts, automatically updating DNS records when IP addresses change.
> 
> ## Implementation Details
> - **26 comprehensive unit tests** covering all functionality
> - **Follows existing provider patterns** for consistency
> - **Available as both `aliesa` and `esa` provider names**
> - **Complete documentation** with configuration examples and troubleshooting
> - **Error handling and logging** for debugging and monitoring
> 
> The provider integrates seamlessly with the existing DDNS framework while adding ESA-specific optimizations for both ease of use and security.
> 
> Fixes #490.
