## 📝 Pull Request Body (Autor: Copilot)

> Implements automatic HTTP retry functionality with exponential backoff to handle network errors and server issues gracefully.
> 
> ## Changes
> 
> ### Core Implementation
> - **RetryHandler Class**: New HTTP handler with configurable retry logic
> - **New `request()` Function**: requests-style interface with built-in retry capability  
> - **Exponential Backoff**: 2^n seconds wait time (2s, 4s, 8s...)
> - **Smart Retry Logic**: Only retries specific conditions, not all errors
> 
> ### Retry Conditions
> - **HTTP Status Codes**: `408, 429, 500, 502, 503, 504`
> - **Network Exceptions**: socket.timeout, socket.gaierror, socket.herror
> - **Python 2/3 Compatible**: Handles different exception types across versions
> 
> ### Configured Retry Counts
> - **DNS Providers**: 2 retries (via `ddns/provider/_base.py`), MAX 3 requests
> - **IP Detection**: 2 retries (via `ddns/ip.py`)  
> - **Configurable**: Custom retry counts via `retries` parameter
> 
> ## Usage Examples
> 
> ```python
> from ddns.util.http import request
> 
> # Basic usage with default no more retries
> response = request('GET', 'https://api.example.com/dns')
> 
> # Custom retry count
> response = request('POST', 'https://api.example.com/update', 
>                    data='{"record": "A"}', retries=2)
> 
> # With proxy support (requests-style)
> response = request('GET', 'https://api.example.com/ip', proxy='https://proxy:8080')
> ```
> 
> ## Testing
> - **33 Tests**: Comprehensive coverage including retry scenarios
> - **Mock-based**: Tests retry logic without network dependencies  
> - **Real Network**: Validates actual HTTP functionality
> - **Edge Cases**: Non-retryable errors, max retries exceeded, etc.
> 
> ## Network Error Handling Before/After
> 
> **Before**: Single network failure = immediate failure
> ```python
> # Any network hiccup causes DNS update to fail
> URLError: <urlopen error [Errno 111] Connection refused>
> ```
> 
> **After**: Automatic retry with exponential backoff
> ```python
> # Network hiccup triggers automatic retry
> WARNING: Request failed, retrying in 1 times: Connection refused
> WARNING: Request failed, retrying in 2 times: Connection refused  
> ```
