> ![high](https://www.gstatic.com/codereviewagent/high-priority.svg)
> 
> Using `unittest.mock.patch` to disable garbage collection is unconventional for production code. The `gc` module provides a direct API for this purpose (`gc.disable()` and `gc.enable()`) which is more idiomatic and clearly expresses the intent to control automatic garbage collection.
> 
> This implementation also disables manual calls to `gc.collect()`, which is a stronger guarantee than `gc.disable()`. If the goal is simply to prevent *automatic* GC from running during the critical section, `gc.disable()` is sufficient and preferred. If you must prevent manual calls as well, please add a comment explaining why this is necessary.
> 
> Assuming the goal is to prevent automatic GC, here is a more idiomatic implementation:
> 
> ```python
>     @contextmanager
>     def suppress_gc_collect(self):
>         """Temporarily disable automatic garbage collection to speed up CUDA graph capture."""
>         was_enabled = gc.isenabled()
>         if was_enabled:
>             gc.disable()
>         try:
>             yield
>         finally:
>             if was_enabled:
>                 gc.enable()
> ```

### 💬 [COMENTÁRIO GERAL] por **zou3519** em 2025-07-18 13:19:13

> On the PyTorch side, the motivation of https://github.com/pytorch/pytorch/pull/158193 is that pytorch shouldn't force people to gc.collect when doing the cuda graph recording. Users should get that flexibility to choose.
> 
> For vLLM, doing GC at least for at the beginningn of all piecewise captures seems good. The idea is that we want to free up memory so that we have enough memory to do the CUDAGraph captures.
> 
> Doing GC once per shape is a reasonable thing to do, though -- the capture of each shape is a forward pass through the model, and it may be possible for there to be a reference cycle somewhere that holds onto memory. But maybe we should consider these situations to be bugs and fix them, the startup time savings are significant.

> Function:

>             Only calls the original gc.collect every N invocations.
>             """
>             original_gc_collect = gc.collect
>             call_count = 0
