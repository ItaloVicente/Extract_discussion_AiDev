## 📝 Pull Request Body (Autor: jlowin)

> ## Summary
> 
> This PR addresses issue #91 by adding support for Python version specification and dependency management options to FastMCP's CLI commands. Users can now specify Python versions and dependencies without manually editing configuration files.
> 
> The implementation adds three new options as passthroughs to `uv run`:
> - `--python`: Specify Python version (e.g., `--python 3.11`)
> - `--project`: Specify a project directory for UV workspace packages
> - `--with-requirements`: Specify a requirements file for additional dependencies
> 
> ## Example Usage
> 
> Previously, users had to manually edit configuration files to specify Python versions. Now they can do:
> 
> ```bash
> # Run a server with specific Python version
> fastmcp run server.py --python 3.11
> 
> # Run with a requirements file
> fastmcp run server.py --with-requirements requirements.txt
> 
> # Install to Claude Desktop with Python 3.10
> fastmcp install claude-desktop server.py --python 3.10 --project /workspace
> 
> # Development mode with all options
> fastmcp dev server.py --python 3.11 --with-requirements dev-requirements.txt --project .
> ```
> 
> ## Implementation Details
> 
> The changes maintain backward compatibility by only using `uv run` subprocess execution when UV-specific options are provided. When no UV options are specified, the existing direct Python import behavior is preserved.
> 
> ### Key Changes:
> 1. Added new parameters to `run` and `dev` commands
> 2. Added new parameters to all install commands (claude-desktop, claude-code, cursor, mcp-json)
> 3. Created `run_with_uv` function to handle subprocess execution
> 4. Updated `_build_uv_command` to support new options with correct argument ordering
> 5. Added comprehensive unit tests for all new functionality
> 6. Updated documentation across all relevant pages
> 
> ### Documentation Updates:
> - CLI usage patterns
> - Running server guide with new dependency management section
> - Integration guides for Claude Desktop, Claude Code, and Cursor
> - MCP JSON configuration examples
> 
> This provides a much better developer experience for users who need specific Python versions or have complex dependency requirements.
