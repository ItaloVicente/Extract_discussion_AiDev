### 📝 [PR BODY] por **Michaelvll** em 2025-06-23 23:19:08

> Unit tests were generated for `sky cost-report` to prevent regressions.
> 
> *   A new test file, `tests/unit_tests/test_sky_cost_report.py`, was created, containing classes for `TestCostReportCore`, `TestCostReportStatusUtils`, `TestCostReportServer`, and `TestCostReportCLI`.
> *   An initial `UNIT_TESTS_SUMMARY.md` was also created to document the test coverage.
> 
> Based on feedback, the test suite was refined:
> 
> *   The `TestResourceParsingRegression` class was removed from `test_sky_cost_report.py` as resource parsing tests were deemed unnecessary for this regression prevention.
> *   A new class, `TestHistoricalClusterRobustness`, was added to `test_sky_cost_report.py` to address critical robustness concerns. This class includes tests for:
>     *   Handling historical clusters with instance types not found in current catalogs.
>     *   Graceful degradation when resource data is `None`, corrupted, or incomplete.
>     *   Processing clusters with empty or malformed usage intervals.
>     *   Ensuring valid clusters are processed correctly even when other historical data is problematic.
>     *   Special handling for controller cluster names.
> *   `UNIT_TESTS_SUMMARY.md` was updated to reflect these changes, emphasizing the focus on historical data robustness.
